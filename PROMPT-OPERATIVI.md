# Nabooq · Instagram: prompt operativi (v2)

Il piano settimanale parte **da solo ogni lunedì**: c'è un'attività programmata. I prompt qui sotto servono solo quando vuoi intervenire a mano, in una nuova chat del progetto. Le parti tra [parentesi quadre] vanno compilate o cancellate.

---

## 1. Notizia calda (da usare subito quando esce qualcosa di grosso)

```
Post singolo, notizia calda.
Notizia: [link o descrizione].
Pubblica: [oggi alle HH:MM | domani alle 12:30 | prossimo slot libero].
Se serve, sposta il post della rubrica di quel giorno e dimmi cosa hai spostato.
```

## 2. Piano settimanale a mano (se l'attività automatica non è partita)

```
Fai la settimana.
Settimana: [lunedì GG/MM/AAAA].
Note: [temi da evitare, eventi, oppure "nessuna"].
```

## 3. Analisi approfondita (una volta al mese)

```
Analisi del mese di [mese].
Usa le statistiche di Buffer e learnings.md.
Dimmi quali ganci, formati e rubriche portano più condivisioni e salvataggi, se spostare gli orari e cosa provare il mese prossimo. Aggiorna learnings.md.
```

## 4. Revisione

```
Revisione del post [data o tema].
Cosa cambiare: [es. "cover più forte", "slide 3 troppo tecnica", "caption più corta"].
Rigenera, aggiorna GitHub e il post su Buffer. Mantieni data e orario.
```

## 5. Cambio di regole

```
Da ora in poi: [es. "pubblica direttamente senza bozze", "4 post a settimana", "niente temi legali"].
Aggiorna learnings.md e ISTRUZIONI-AGENTE.md nel repository, così l'attività del lunedì lo applica.
```
